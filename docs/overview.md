# AutoDevAgent Overview

## 프로젝트 목적

MDR 의료기기 SW 과제 관리를 위한 Jira-GitHub 자동화 플랫폼입니다. AI를 활용하여 추적성 관리를 자동화하고, 의료기기 개발 프로세스를 효율화합니다.

## 핵심 기능

### 1. AI 기반 문서 생성
- 사용자의 간단한 명령으로 전문적인 문서 자동 생성
- Intended Use, SRS, SDS, Architecture 등 다양한 산출물 지원

### 2. 추적성 자동 관리
- 티켓 간 자동 링크 및 관계 설정
- 하향식/상향식 추적성 매트릭스 생성

### 3. 멀티-프로젝트 지원
- 다수의 Jira 보드와 GitHub 레포 쌍 동시 관리
- 프로젝트별 독립 작업 공간

### 4. 자동화된 워크플로우
- 문서 생성 → 리뷰 → 수정 → 구현까지 자동화
- 사용자는 Jira 코멘트로 명령 전달

## 기술 스택

- **AI**: Claude (Anthropic)
- **에이전트 프레임워크**: Goose
- **CI/CD**: GitHub Actions
- **인프라**: Docker (로컬 호스트)
- **이슈 트래커**: Jira
- **버전 관리**: GitHub

## 빠른 시작

1. Jira 티켓 생성 (예: "CBCT 웹 뷰어 만들어줘")
2. 티켓 코멘트로 명령 전달 (예: "@bot generate intended-use")
3. AI가 문서 생성 및 Jira 티켓 자동 생성
4. 리뷰 및 수정 (코멘트 활용)
5. 산출물 자동 생성 및 링크
6. 구현 진행
